***Docker

Docker is an open-source containerization platform. This Docker tool designed to make it easier to create, deploy and run application by using containers.

***Docker images

Docker image is a package. that have everything to run an application.
Set of instruction stored in the form of layer. Each layer is read only.

***Docker containers

Docker container is a standardized unit which can be create on the fly to deploy a particular application or environment.
It’s a running instance of an image. Container are writable.

Docker networs
	* Bridge -- default network, used when application run in isolation containers that need to be communicated
	* Host -- removes the network isolation between the containers and docker host
	* overlay -- this will interact multiple docker hosts
	* ipvlan -- this will controles ipv4 and ipv6
	* maclan -- this allows to assign the mac address to container 
	* none -- disbales all the network part
